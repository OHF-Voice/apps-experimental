# The command library (Spanish)

Comandos de ejemplo para la biblioteca de la interfaz web (Spanish), as the
English library (voice_labs/languages/en/library/): titles and
needs are the UI's, in English; descriptions are said in hints ("Parece que
quieres <description>, ..."), so each is what one wants to do: "encender la
luz".

Keywords are lowercase, with their accents, as the Spanish model writes
them. Articles and "en", "de", "del", "a", "al" are filler (the language
pack's): "enciende la luz del salón" is "enciende" + "luz" and a place.
