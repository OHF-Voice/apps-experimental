# The command library (German)

Beispielbefehle für die Bibliothek der Weboberfläche (German). Adding one
copies it into the home's commands, where it can be changed like any other
command.

As the English library (voice_labs/languages/en/library/): titles
and needs are the UI's, in English; descriptions are said in hints ("Es
sieht so aus, als wolltest du <description>, ..."), so each is what one
wants to do: "das Licht einschalten".

Keywords are lowercase, as the German model writes them lowercased:
separable verbs by their parts ("schalte das Licht ein": "licht" + "ein").
Articles and "im", "in der" are filler (the language pack's), and a room
may be joined to what is in it ("Küchenlicht": compounds).
