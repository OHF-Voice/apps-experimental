# The command library (French)

Exemples de commandes pour la bibliothèque de l'interface web (French), as
the English library (voice_labs/languages/en/library/): titles
and needs are the UI's, in English; descriptions are said in hints ("On
dirait que vous voulez <description>, ..."), so each is what one wants to
do: "allumer la lumière".

Keywords are lowercase with their accents. Articles, "de", "dans" are
filler (the language pack's); a name may be heard with its article joined
("dans l'entrée").
