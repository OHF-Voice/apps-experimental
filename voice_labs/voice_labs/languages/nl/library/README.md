# The command library (Dutch)

Voorbeeldopdrachten voor de bibliotheek van de webinterface (Dutch), as the
English library (voice_labs/languages/en/library/): titles and
needs are the UI's, in English; descriptions are said in hints ("Je wilde
zeker <description>, ..."), so each is what one wants to do: "het licht
aandoen".

Keywords are lowercase, separable verbs by their parts ("doe het licht
aan": "licht" + "aan"; "schakel ... in"). Articles and "in", "op" are filler
(the language pack's), and a room may be joined to what is in it
("keukenlamp": compounds).
