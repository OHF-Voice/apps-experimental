# The command library (Russian)

Примеры команд для библиотеки веб-интерфейса (Russian), as the English
library (voice_call/languages/en/library/): titles and needs are
the UI's, in English; descriptions are said in hints ("Похоже, вы хотите
<description>, ..."), so each is what one wants to do: "включить свет".

Keywords are lowercase, with "е" for "ё", as the Russian model writes them,
in the forms people say: imperatives both ways ("включи", "включите") and
nouns in their cases ("лампу", "лампы"). "В", "во", "на" and "мой" are
filler (the language pack's): "включи свет на кухне" is "включи" + "свет"
and a place. A device's name is heard in its cases too ("включи лампу" for
the Лампа). What is said back of a device by name takes no gender it can't
know: "Включено: Торшер."; a question about one guesses it from the name's
first word ("Лампа включена", "Торшер включён").
