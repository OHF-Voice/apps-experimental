# The command library (Italian)

Example commands for the web UI's library (Italian), as the English
library (voice_call/languages/en/library/): titles and needs are
the UI's, in English; descriptions are said in hints ("Sembra che tu voglia
<description>, ..."), so each is what one wants to do: "accendere la luce".

Keywords are lowercase with their accents. Articles and prepositions ("la",
"nel", "della") are filler (the language pack's); a name may be heard with
its article joined ("nell'ingresso").
