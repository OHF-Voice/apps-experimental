# The command library (Ukrainian)

Приклади команд для бібліотеки веб-інтерфейсу (Ukrainian), as the English
library (voice_call/languages/en/library/): titles and needs are
the UI's, in English; descriptions are said in hints ("Схоже, ти хочеш
<description>, ..."), so each is what one wants to do, an infinitive:
"увімкнути світло".

Keywords are lowercase, in the forms people say them: imperatives both ти
and ви ("увімкни", "увімкніть"), nouns in their cases ("лампу", "лампи"),
with the apostrophe the model writes ("п'ять"). "Увімкни" is also written
"ввімкни", and the model hears it as "умкни". Prepositions and "будь
ласка" are filler (the language pack's): "увімкни світло у вітальні" is
"увімкни" + "світло" and a place.

What is said back is impersonal ("Світло увімкнено") and names a device
after a colon ("Увімкнено: Торшер"), so a name, which can't be declined,
never has to agree with anything; numbers with units agree with them ("22
градуси", "5 відсотків").
