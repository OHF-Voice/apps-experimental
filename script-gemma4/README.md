# Gemma 4 Script Runner

A [conversation][] agent built with [Gemma 4][gemma4] that runs Home Assistant [scripts][] which have been [exposed][expose] to voice.

This app is experimental: it only runs scripts you write for it, and response times depend heavily on your hardware.

See [the documentation][docs] for more details.
